# GovGazette for Antigravity

This plugin connects the public GovGazette MCP server and includes contract research and exclusion review skills. Public research needs no account or API key.

From a checkout of [govgazette-mcp](https://github.com/mooshee/govgazette-mcp), install it in Antigravity CLI:

```sh
agy plugin install ./antigravity-plugin
agy plugin list
```

For Antigravity 2.0 or the standalone IDE, place this directory at `.agents/plugins/govgazette/` for one workspace or `~/.gemini/config/plugins/govgazette/` for all workspaces. Reload the host and enable GovGazette's tools when prompted.
